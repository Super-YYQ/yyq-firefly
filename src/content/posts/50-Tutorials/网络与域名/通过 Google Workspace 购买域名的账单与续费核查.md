# 通过 Google Workspace 购买域名的账单与续费核查

注册 Google Workspace 时，可以在部分流程中同时购买新域名；域名注册由合作方 Squarespace 提供。网络上流传的“土耳其区约 75 里拉、续费同价”来自个别交易记录，**不是当前价格或长期续费承诺**。购买前应以自己有资格使用的账单地区、结账页面和实际续费条款为准。[Google 购买域名说明](https://knowledge.workspace.google.com/admin/domains/purchase-a-domain-when-you-sign-up-for-google-services)

## 购买前核对什么

| 项目 | 要核对的问题 |
| --- | --- |
| 域名注册费 | 所选后缀、首年价格、币种、税费和结账总额是什么？ |
| 续费 | 自动续费是否开启；下一年度显示的费用与条款是什么？ |
| Workspace 订阅 | 试用结束后是否自动转为付费，取消时是否有未结清费用或固定期限承诺？ |
| 账单地区 | 所选国家是否与你真实的业务或居住及付款资料一致？ |
| 域名管理 | 注册成功后由哪个账户管理域名、续费和登录方式？ |

Google 的付款方式和币种取决于账单国家。部分地区还要求付款方式的账单地址与账单国家一致；账单国家设置后变更受限。**不要为获得区域价格填写不实地址。**[付款方式说明](https://knowledge.workspace.google.com/admin/billing/payment-options-in-my-country) · [账单地址说明](https://knowledge.workspace.google.com/admin/billing/payment-method-faq) · [账单国家说明](https://knowledge.workspace.google.com/admin/support/troubleshooting/selected-wrong-billing-country)

## 注册与购买时的检查点

1. 从 [Google Workspace 官网](https://workspace.google.com/) 开始注册，按页面提示选择**购买新域名**，而非绑定已有域名。界面和可购买的后缀可能随地区与时间变化。
2. 选择域名后，在付款前逐项核对注册费、币种、税费、自动续费设置及 Workspace 订阅费用。若价格或条款与预期不符，先停在结账页查明原因。
3. 只提交真实、可验证的企业或个人及付款资料。支付和身份验证结果由服务商决定，不应假设某类卡、手机号或地址一定能通过。
4. 购买完成后保留订单和续费通知，确认注册商、管理入口、域名到期日及账户恢复方式。按 Google 发来的邮件核实域名联系人地址；官方说明要求在 15 天内完成验证，否则域名可能被暂停。若域名由 Squarespace 管理，也要确认自己可以独立登录该账户。[Google 购买域名说明](https://knowledge.workspace.google.com/admin/domains/purchase-a-domain-when-you-sign-up-for-google-services)

## 不再使用 Workspace 时

取消 Workspace **订阅** 与删除整个组织 **账号** 是两件事。取消前先导出需要保留的邮件和文件，查看订阅计划及可能的剩余费用。如果注册时一并购买域名，保留域名注册服务，并确认后续能够访问 Squarespace。Google 提醒：删除 Workspace 账号前若未转移域名管理权限，可能失去对 Squarespace 域名的访问。[Google 取消 Workspace 指南](https://knowledge.workspace.google.com/admin/billing/cancel-google-workspace)

域名到期前还要检查自动续费与付款方式是否有效。实际续费价格以管理后台、到期提醒和当年的服务条款为准；不能从一次历史扣款推断多年都同价。[Google 域名续费说明](https://knowledge.workspace.google.com/admin/support/troubleshooting/what-if-my-domain-expires)

如果之后要更换 DNS 服务商，可以单独修改域名的名称服务器；这不会自动把注册商迁走。操作前先保存网站和邮箱 DNS 记录，避免服务中断。具体步骤见 [[Squarespace 域名迁移到 Cloudflare DNS]]。
